# Pitang Labs POC Simulator - OpenAI Codex Guide

## Quick Start
Run the following command in Codex terminal or prompt:
```bash
npx pitang-poc
```

## Functionality
- Spawns local HTTP server with all categorized POC flows.
- Automatically launches the IDE webview / Simple Browser tab via `vscode.simple-browser` or system browser.
- Supports hot-reloading requirements and business rules.

## Design Rules Enforced
- Concentric geometry: Outer radius equals inner radius plus padding.
- Touch targets: Minimum 44x44px.
- Tabular figures for numbers, counters, and metrics.
- Physical spring motion with zero layout shifts.
